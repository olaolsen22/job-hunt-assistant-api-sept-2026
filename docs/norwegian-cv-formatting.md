# Norwegian CV formatting — comparison of official Norwegian guidance

Research date: **12 October 2026**. Language: English, retaining Norwegian section names where useful.

## Scope and evidence

This report compares public Norwegian CV guidance from national services, public universities, and public county career centres. It covers ordinary job applications; academic and project-funding formats are identified separately. Only official Norwegian websites support the findings. Commercial CV services, recruitment blogs, Reddit, and private professional associations are excluded, including commercial sites linked by public services.

This is a broad review of relevant, publicly accessible guidance, **not an exhaustive inventory of every official Norwegian website**. Several sites share institutional owners: NAV and Arbeidsplassen are one source family, while Utdanning.no and Karriereveiledning.no are HK-dir services. Agreement between their pages should not be counted as wholly independent institutional evidence. HK-dir documents its services [here](https://hkdir.no/om-oss/tenester); ung.no identifies Bufdir as its operator [here](https://www.ung.no/om/403_Kontakt_ung.no.html).

Evidence labels:

- **Shared guidance:** multiple reviewed official sources recommend it.
- **Source-specific:** an explicit recommendation from a named source; not a national rule.
- **Context-specific:** a requirement for a particular academic/project template.
- **Not established:** the reviewed sources do not provide a general specification. This does not mean no official source anywhere discusses it.

## 1. Similarities across the sources

| Formatting or presentation feature | Comparison finding | Official support |
|---|---|---|
| Overall appearance | Short, orderly, readable, and easy to scan. | [NTNU][S5], [NMBU][S6], [Østfold][S8], [Karriereveiledning][S3] |
| Length | Usually **1–2 pages** for ordinary applications. Several guides explicitly cap it at two. | [Utdanning.no][S2], [ung.no][S7], [NMBU][S6], [UiB][S10], [Telemark][S9] |
| Chronology | Newest education and employment entries first. | [NAV/Arbeidsplassen][S1], [NMBU][S6], [Østfold][S8], [Telemark][S9] |
| Sections | Separate contact details, experience, education, skills, and other relevant qualifications. | [NAV/Arbeidsplassen][S1], [ung.no][S7], [Karriereveiledning][S3] |
| Descriptions | Brief facts, keywords, or bullet points rather than long prose. | [Utdanning.no][S2], [ung.no][S7], [UiB][S10] |
| Relevance | Adapt content and emphasis to the vacancy. | [NAV/Arbeidsplassen][S1], [NMBU][S6], [Karriereveiledning][S3] |
| Consistency | Apply fonts and formatting consistently. | [NTNU][S5], [Østfold][S8], [Telemark][S9] |
| Photo | Optional; a professional, neutral image if included. | [NTNU][S5], [Østfold][S8], [NMBU][S6] |
| Electronic applications | Complete the required CV categories in the recruitment system. | [Karriereveiledning][S4], [ung.no][S7], [Telemark][S9] |

**Interpretation:** the common pattern is a concise CV organized into recognizable sections. The sources do not establish one compulsory national visual template. NMBU explicitly says there is no single correct CV or template [S6]; Utdanning.no nevertheless recommends a formal, structured presentation [S2].

## 2. Fonts, headings, colors, and visual hierarchy

| Detail | What the official guidance actually says | Status |
|---|---|---|
| Font family | Østfold recommends a readable **standard font**; it does not name a mandatory family. [S8] | Source-specific |
| Font size | Østfold specifies **10–12**. The article does not distinguish body and heading sizes. [S8] | Source-specific |
| Consistent typography | Use the same font/style throughout; be consistent about size and emphasis. [S5, S8, S9] | Shared guidance |
| Applicant name | NTNU recommends a name in bold and larger type; the heading “Curriculum Vitae” is unnecessary. [S5] | Source-specific |
| Section headings | UiB recommends clear headings; Østfold says to emphasize them. [S10, S8] | Shared guidance |
| Colors | Østfold recommends neutral colors. [S8] | Source-specific |
| Italics, underlining, decorative rules | No general specification identified. | Not established |
| Heading/name sizes in points | No general numeric specification identified. | Not established |

Do not interpret NAV or university website branding fonts as instructions for an applicant's CV. Likewise, a font visible in an example is not automatically an explicit recommendation.

| Space before/after paragraphs | No point values identified. |
| Space between sections or entries | No numeric specification identified. |

| Left alignment versus justification | No explicit general rule identified. |
| One column versus two columns | No general prohibition or requirement identified. |
| Tables | No general ban identified. Utdanning.no's template page even describes adding/removing rows. [S11] |
| Text boxes, sidebars, headers/footers | No general compatibility rule identified. |

| Bullets | Simple, pointwise presentation is explicitly supported. [S2, S7, S10] |

Consequently, claims such as “Norwegian CVs must use 1.15 line spacing, 2 cm margins, and a single column” are **not established by the reviewed general guidance**. These parameters remain design choices unless the employer or a required template specifies them.

### A genuine official numeric specification — with a limited scope

UiB hosts a Norwegian project/research CV template with these explicit instructions on its first page:

| Parameter | Template requirement |
|---|---|
| Maximum length | 4 pages |
| Page size | A4 |
| Margins | 2 cm |
| Line spacing | Single |
| Font | Times New Roman |
| Font size | 12 point |

It includes project roles, research supervision, teaching, and scientific activities. **These are requirements of that particular template, not a general Norwegian employment-CV standard.** Its continued availability does not establish that it is the current required format for a particular funding call. Check the current call before using it. [UiB project CV template, p. 1][S12]

## 4. Section order, dates, and entry presentation

### Order and emphasis

The usual components are contact information, qualifications/profile, work experience, education, other experience, courses/certificates, languages, IT skills, and references. Include the sections relevant to the job rather than filling space with everything you have done. [Karriereveiledning][S3]

Education can precede work experience for students and recent graduates; otherwise choose emphasis according to relevance. Telemark explicitly identifies this student/graduate exception. [Telemark, p. 7][S9]

A profile is not universally compulsory. UiB suggests a brief introductory paragraph near the top; NAV recommends a tailored qualifications summary. [UiB][S10], [NAV/Arbeidsplassen][S1]

### Dates and repeated entry structure

- NAV asks for education start/end dates and job periods, with the latest entries first. [S1]
- NMBU explicitly requests employment dates by month and year. [S6]
- Østfold gives **mm.åå–mm.åå**, while Telemark's template uses **mm.åååå–mm.åååå**, including **d.d.** for an ongoing position. These are different official examples, not one obligatory national date syntax. [S8, S9]
- A repeatable entry can present **date range, role/degree, organization/institution**, followed by brief relevant descriptions. This is a synthesis of NAV and NMBU's instructions. [S1, S6]

### Foreign experience and location formatting

NMBU encourages including international study/work experience, but its guidance does not prescribe whether an employment location should contain the city, country, or both. No general city-versus-country rule was established by the sources reviewed for this report. [NMBU][S6]

**Suggested implementation, not an official Norwegian requirement:** use **City, Country** for foreign experience so the location is unambiguous. Keep the same entry structure across roles. For example, using fictional information:

**Project Coordinator**  
Example Company, Lagos, Nigeria  
01.2021–06.2023

This location choice is intended for reader clarity; no ATS compatibility claim is made. Follow a recruitment portal's separate city/country fields when those are provided.

### Skills, language, and references

Describe language ability in words and distinguish written/spoken proficiency where useful. Karriereveiledning provides levels such as native, fluent, good, and basic. [5 tips for your CV][S13]

NTNU favors listing IT tools rather than assigning self-ratings. It also specifies that references belong last and that the CV should match the advertisement's language. [S5]

References can be supplied on request; ask people before naming them. This is supported by the national careers guidance. [S13]

## 5. ATS and digital recruitment: supported advice versus unverified claims

ATS means applicant tracking system. The official sources reviewed discuss recruitment portals and electronic CVs, but do not establish a general technical standard guaranteeing automatic parsing or selection.

### What official sources support

1. **Follow the employer's submission instructions.** Karriereveiledning describes different routes, including direct system entry, document uploads, and email. [S4]
2. **Complete the portal CV fields.** Jobbnorge and Webcruiter are named examples. An attached CV should not be assumed to replace required system entries. [S4]
3. **Have both versions ready:** a CV document and information entered into relevant digital systems. [S4]
4. **Use accurate vacancy terminology.** Karriereveiledning recommends relevant words from the advertisement; this supports recognizable descriptions, not claims about an ATS score. [S3]
5. **Use descriptive sections and short bullets.** UiB recommends recognizable headings and bullet lists for readability. Its advice does not certify any particular parser. [S10]
6. **Use PDF where appropriate.** Telemark explicitly recommends sending CVs as PDF. Employer/portal instructions still determine the accepted format for a specific application. [S9, S4]
7. **Keep contact details as ordinary, labeled text.** The sample uses separate lines such as `Telefon:`, `E-post:` and `Bosted:`. This avoids relying on icons, dot separators, graphics, text boxes, or document-header fields. It is a practical parsing precaution, not an official Norwegian ATS rule.
8. **Write foreign locations as `City, Country`.** For example, `Example Company, Lagos, Nigeria`. This keeps the location explicit in extracted text. NMBU supports including international experience but does not prescribe a city/country format, so this is a practical convention rather than official ATS guidance. [S6]

### What this research does not establish

| Common ATS claim | Evidence status in the reviewed official sources |
|---|---|
| Every CV must be one column | Not established. |
| All tables prevent parsing | Not established; public templates can use rows/tables. [S11, S12] |
| DOCX always beats PDF, or PDF always beats DOCX | No universal ATS rule established. Telemark recommends PDF for CV documents. [S9] |
| Certain fonts cause automatic rejection | Not established. |
| Contact details in headers are always missed | Not established. |
| Photos, icons, or skill bars automatically cause rejection | Not established. Photo optionality does not prove parser compatibility. |
| A fixed keyword percentage or ATS score is required | Not established. |
| A PDF that looks correct is guaranteed to parse correctly | Not established. |

**Practical implication, inferred from the portal guidance:** check that the information required by the system is actually present in its fields. Do not equate an attractive uploaded document with a complete electronic application. [S4, S9]

This report deliberately avoids filling the technical evidence gaps with commercial ATS advice, because the research is restricted to official Norwegian sources.

## 6. Academic CVs are a separate context

UiB distinguishes short non-academic CVs from academic CVs that may run to several pages and include publications, conferences, and teaching. [S10]

OsloMet also discusses narrative CVs for researchers, using connected prose to explain contributions and impact. This is an exception to the ordinary pointwise employment format, not a reason to replace a general job CV with a research narrative. [OsloMet][S14]

## 7. Consolidated application checklist

This checklist combines the official advice above; it is not a national mandatory template.

- [ ] CV is usually within 1–2 pages for an ordinary role. [S2, S7]
- [ ] Layout is easy to scan and the relevant experience receives the most space. [S6, S8]
- [ ] Education and employment run newest first. [S1, S6]
- [ ] Headings clearly separate the sections. [S10]
- [ ] Font, emphasis, and date treatment are consistent. [S5, S8]
- [ ] A readable standard font is used; Østfold's published size guidance is 10–12. [S8]
- [ ] Descriptions are concise and specific to the vacancy. [S3, S13]
- [ ] Spelling and language have been checked. [S6, S7]
- [ ] Required portal categories are completed, alongside any requested upload. [S4]
- [ ] Submission format follows the employer; Telemark recommends PDF for a document CV. [S4, S9]
- [ ] Any research/funding template is checked against its own instructions. [S12]

## 9. Finished fictional sample CV

Created 13 October 2026: [Sample Norwegian CV — fictional information](Sample_Norwegian_CV_Fictional.pdf).

The sample is a finished, one-page Norwegian-language CV. The person, employment history, qualifications, contact information and results are fictional. Its text is selectable and was checked by PDF text extraction; this is not an ATS certification.

The sample uses the following **implementation choices, not additional official requirements**:

| Element | Sample setting |
|---|---|
| Font family | Arial, with Arial Bold for emphasis |
| Body and contact text | 11 pt |
| Contact information | Separate ordinary text lines labeled Telefon, E-post and Bosted; no dot separators, icons or document header fields |
| Role and degree titles | 11 pt bold |
| Section headings | 13 pt bold |
| Applicant name | 22 pt bold |
| Body line spacing | 14 pt baseline spacing, approximately 1.27 times the font size |
| Section heading spacing | 12 pt before, 6 pt after |
| Body paragraph spacing | 4 pt after; bullets 3 pt after |
| Page | A4; 2 cm left/right margins; 1.7 cm top/bottom margins |
| Layout | One column, left aligned, dark text on white; no photo |

The body size falls within Østfold's published 10–12 range. The larger headings, exact spacing, page margins and choice of Arial illustrate a readable design; they are not prescribed by the reviewed general CV guidance. The cited range does not separately identify sizes for body text, headings or the name.
